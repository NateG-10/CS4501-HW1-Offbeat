Operating instructions

Value and edit settings

The Value field changes either volume or track position. Open Edit settings and choose what numbers apply to, then close that menu and enter your number in Value. The chosen mode remains active until you change it or load a new file. Closing the menu hides the selection; the Value label does not change. Opening Instructions preserves both the mode and the value.

Track position

Choose Track position (seconds) in Edit settings. Enter the desired position as a whole number of seconds, with no colon, spaces, or units, and select Apply. The number must not exceed the track duration. For example, one minute is entered as 60. Applying a position leaves playback paused. Use Play in Other operations to start it. Session particulars shows the resulting elapsed time.

Volume reduction

Choose Volume reduction in Edit settings. Enter a whole number from 0 to 100, calculated as 100 minus your desired volume percentage, then select Apply. A value of 0 gives full volume and 100 gives silence. Decimals, signs, spaces, and percent symbols are not accepted. New files start in Volume reduction mode. Session particulars shows the resulting volume.

Loop command

To repeat the current track, enter cycle-track and select Execute. To turn repetition off, enter single-pass and select Execute. Match the spelling and lowercase letters exactly; do not add spaces. The command field clears after a valid command. The square on the player reports the resulting state using the colors below.

Loop enabled Loop disabled

Playback and notices

Play is inside Other operations below the player. Pause is in the source panel. Session particulars contains playback state, elapsed time, and track length. Input errors appear above the player. Selecting Play opens a confirmation: red Continue starts playback; green Stop leaves it paused. Your file and entered values remain in place when you return.
